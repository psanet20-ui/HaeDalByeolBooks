# HaeDalByeolBooks

해달별(HaeDalByeol, HDB)의 창작 동화와 출간 소식을 모아 두는 1인 출판 브랜드 공식 홈페이지입니다.

이 사이트는 작품 전문 공개용이 아니라, 작품 소개와 유튜브 영상, 편지 발췌, 전자책/종이책 출간 소식을 연결하는 허브로 운영합니다.

## 현재 구성

- 홈: 해달별 배너와 HaeDalByeolBooks 소개
- 책장: 현재 소개 작품과 다음 이야기 자리
- 작품 소개: `나 떠난 후에` 소개, 유튜브 채널 연결, 출간 준비 현황, 편지 발췌

## 파일

- `index.html`: 공식 홈페이지 구조와 스타일이 들어 있는 단일 HTML 파일
- `assets/HDB-banner.png`: 해달별 채널 배너 이미지
- `assets/HDB-logo.png`: 해달별 로고 이미지
- `README.md`: 프로젝트 설명과 배포 방법

## 운영 방향

- 유튜브에는 영상으로 보는 이야기 연결
- 홈페이지에는 작품 소개, 발췌문, 출간/판매 링크 정리
- 전자책과 종이책 출간 시 구매 링크와 ISBN 정보를 추가
